# Практическая работа 1, вариант 32

Эмулятор командной строки на Python 3.8 или новее. Файловая система
загружается из XML и хранится в памяти. В ней можно перемещаться по
каталогам, смотреть файлы и создавать новые. Команды записываются в CSV.

Поддерживаются `ls`, `cd`, `head`, `wc`, `who`, `touch` и `exit`.
Можно использовать относительные и абсолютные пути, кавычки и переменные
окружения. `touch` меняет файлы только в памяти, исходный XML не меняется.

Для запуска не нужны дополнительные библиотеки:

```bash
./run.sh --vfs vfs/sample.xml --log logs/session.csv
```

Чтобы выполнить готовый список команд, добавь параметр `--script`:

```bash
EMU_HOME=/home/student ./run.sh --vfs vfs/sample.xml \
  --log logs/demo.csv --script startup_scripts/stage4_commands.txt
```

`--vfs` и `--log` обязательны. В `vfs` есть примеры файловых систем,
а в `startup_scripts` — примеры команд. В XML каталоги задаются элементами
`directory`, файлы — `file`; двоичные данные записываются в base64.

После ошибок программа продолжает выполнять команды. При завершении
она один раз выводит `Errors были во время исполнения`. Если ошибок
не было, этой строки нет. Код возврата: 0 — без ошибок, 1 — ошибки команд,
2 — ошибка загрузки VFS, скрипта или журнала.

Код находится в `main.py` и `src/shell_emulator`. Тесты можно запустить
командой `make check`. Она выполняет модульные тесты и 5 сценариев запуска.
Для отдельных проверок есть `make test` и `make system-test`.
