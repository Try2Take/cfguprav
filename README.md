# Практическая работа 1, вариант 32 — этап 4

Эмулятор командной строки на Python 3.8 или новее. VFS загружается из
XML в память; поддерживаются относительные и абсолютные пути, кавычки,
переменные окружения и CSV-журнал вызовов команд.

На этом этапе работают `ls`, `cd`, `head`, `wc`, `who` и `exit`.
У `ls` есть ключи `-l`, `-a`, `-h`, которые можно комбинировать.
`head` читает первые строки, `wc` считает строки, слова и байты,
`who` показывает пользователя текущей сессии. Ошибки команд не
останавливают сценарий и отражаются в журнале и итоговом коде возврата.

Запуск: `./run.sh --vfs vfs/sample.xml --log logs/session.csv`.
Для стартового скрипта добавьте `--script startup_scripts/stage4_commands.txt`.
Проверка всех команд и системных сценариев: `make check`.
