# Практическая работа 1, вариант 32 — этап 2

Эмулятор принимает `--vfs`, `--log` и необязательный `--script`. Пока
путь VFS только выводится при запуске: загрузка XML относится к этапу 3.
Приглашение содержит `study-vfs`; `ls` и `cd` остаются заглушками.

События команд записываются в CSV с полями `timestamp`, `command`,
`arguments`, `error`. Стартовый скрипт поддерживает строки-комментарии,
показывает ввод и вывод и продолжает работу после ошибок. Код возврата 1
означает ошибку команды, 2 — ошибку файла скрипта или журнала.

Запуск: `./run.sh --vfs vfs/sample.xml --log logs/session.csv`.
Проверка: `make check`.
