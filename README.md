# Практическая работа 1, вариант 32 — этап 3

Эмулятор загружает VFS из XML в память. Каталоги и файлы могут быть вложены;
двоичные данные файла задаются через base64. Имя загруженной VFS видно в
приглашении. Ошибки файла и формата XML сообщаются при запуске. Исходный
XML не изменяется.

Параметры `--vfs`, `--log`, `--script`, CSV-журнал и стартовый скрипт
сохранились с этапа 2. `ls` и `cd` пока выводят название и аргументы;
реальная работа с каталогами появится в этапе 4.

Примеры VFS: `vfs/minimal.xml`, `vfs/sample.xml`, `vfs/deep.xml`.
Запуск: `./run.sh --vfs vfs/sample.xml --log logs/session.csv`.
Проверка: `make check`.
