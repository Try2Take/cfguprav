# Практическая работа 1, вариант 32 — этап 1

Минимальный интерактивный эмулятор оболочки. Приглашение содержит имя
`study-vfs`; парсер раскрывает переменные окружения. `ls` и `cd` пока
выводят название и аргументы, `exit` завершает диалог. Неизвестные команды
и неверные аргументы выводятся как ошибки.

Запуск: `./run.sh`. Проверка: `make check`.

Пример интерактивной работы (`EMU_TARGET=/tmp ./run.sh`):

```text
study-vfs:/$ ls $EMU_TARGET
ls: /tmp
study-vfs:/$ cd /tmp
cd: /tmp
study-vfs:/$ unknown
Ошибка: неизвестная команда: unknown
study-vfs:/$ exit
```
